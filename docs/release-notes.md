# Voxen 0.3.4 — déclenchement des raccourcis corrigé

F12 et les autres touches personnalisées déclenchent maintenant la dictée : le pont Windows ne les filtre plus. L’enregistrement d’une combinaison attend la touche finale, au lieu de retenir Ctrl ou Alt trop tôt. Fermer les réglages pendant la capture ne laisse plus les raccourcis désactivés.
