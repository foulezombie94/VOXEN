# Voxen 0.3.0

- Installateur Windows par utilisateur et mises à jour Squirrel depuis les releases officielles GitHub.
- Bouton « Mettre à jour » sous « Prenez vos marques », avec les vrais états de recherche, téléchargement et installation prête.
- Paramètres → Système : version installée, recherche manuelle, téléchargement en arrière-plan et redémarrage confirmé.
- Recherche automatique après une minute puis à intervalles répartis entre trente minutes et cinq heures ; vérifications reportées pendant une dictée ou un traitement.
- Le redémarrage attend la fin des opérations et l’enregistrement des notes des deux fenêtres. Aucun redémarrage forcé pendant une dictée.
- La configuration publique du compte peut rester dans `%LOCALAPPDATA%\Voxen\cloud-config.json` entre les mises à jour. La base locale, les sessions chiffrées et les clés du Gestionnaire d’identifiants Windows restent à leur emplacement habituel.

La première installation remplace une utilisation portable pour activer les mises à jour. Cette version de l’installateur n’est pas signée Authenticode.
